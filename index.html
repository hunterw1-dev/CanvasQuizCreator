Something went wrong?
The AI says my message is too long, or won't send it.
Copy the short version below instead, which leaves out your materials. In the AI tool, attach your files with the paperclip or + button, paste the instructions, and send.
The reply stopped partway through.
Ask for fewer questions at a time. Lower the counts in step 2, copy and run it, and load those questions. Then set the counts for the rest, run it again, and choose Cancel when asked to replace, so the new questions are added to the end. Fix the counts back before you download.
The AI wrote a paragraph or asked me a question instead.
Reply to it with: Please give me only the JSON, with no other text. Then copy that reply.
Load questions shows an error.
Most often, part of the reply was missed. Clear the box, go back to the AI tab, copy the whole reply again, and paste it.

Step 5 of 5

Download and import into Canvas

Name the quiz, make sure everything below is checked off, then download the file and bring it into your course.

Before you download

    Import it into Canvas

    1. Open the import tool

      Open your course and go to Settings, then Import Course Content.

    2. Choose the file type

      For Content Type, choose QTI .zip file.

    3. Choose your file

      Choose the .zip you downloaded. Leave it zipped.

    4. New Quizzes users

      If you use New Quizzes, check Import existing quizzes as New Quizzes when it's offered.

    5. Import

      Select All content, then Import. When the job says Completed, the quiz appears under Quizzes, unpublished.

    6. Turn on Shuffle answers

      So answer order differs for each student. In Classic Quizzes, click Edit and check Shuffle Answers under Options. In New Quizzes, open the Settings tab and turn on Shuffle answers.

      If you converted an old quiz that has choices like "All of the above" or "Both A and B," edit those before you shuffle, or they'll stop making sense.

    7. Finish and publish

      Check the due date, time limit, and attempts, then Publish.
